# Phase 1 – Brainstorming and Ideation

## Project Title
Standard Laptop Procurement Automation

## Problem Statement
The manual process of handling standard laptop requests requires
manual approval verification and catalog task creation. This may
cause delays and errors in assigning tasks to the Hardware team.

## Proposed Solution
The project uses ServiceNow Flow Designer to automate the creation
of a Catalog Task after a Standard Laptop request is approved.

## Objective
- Automate the laptop procurement process.
- Create a Catalog Task after approval.
- Automatically assign the task to the Hardware group.
- Update the task with the required short description.
- Reduce manual intervention and human errors.

## Technologies Used
- ServiceNow
- Flow Designer
- Service Catalog
- Catalog Tasks

## Expected Outcome
When a Standard Laptop request is approved, a Catalog Task is
automatically created with the short description "Laptop need to
Configured" and assigned to the Hardware assignment group.
